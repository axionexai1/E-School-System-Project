Assignments & Homework

Keeps track of all homework, assignments, and project work assigned by teachers.

Assignment Categories

  • Homework
  • Assignments
  • Project Work
  • Submitted
  • Pending
  • Due Date

Assignment Information

Task Type Description
Homework Daily homework assigned by the teacher.
Assignments Subject assignments with submission deadlines.
Project Work Individual or group projects assigned during the semester.
Submitted Displays all completed and submitted tasks.
Pending Displays tasks that are yet to be completed.
Due Date Shows the submission deadline for each task.

Assignment Features

  • Every task clearly displays whether it is Submitted or Pending.
  • Every task includes its Due Date so students can manage their time.
  • Once a teacher marks a task as completed, it is automatically removed from the Pending list.
  • This keeps the student's task list clean, organized, and stress-free.
