Extra Courses

Extra Courses are optional learning programs uploaded by the School Administrator. Students can enroll in these courses to improve their practical skills and learn beyond the regular school curriculum.

Available Extra Courses

  • Programming
  • Robotics
  • Artificial Intelligence (AI)
  • Spoken English
  • Graphic Design
  • More Courses

Course Information

Course Description
Programming Learn coding fundamentals, problem solving, HTML, CSS, JavaScript, Python, and C++.
Robotics Build and program robots using sensors, motors, and microcontrollers.
Artificial Intelligence Learn machine learning, AI concepts, automation, and intelligent systems.
Spoken English Improve speaking, pronunciation, grammar, and communication skills.
Graphic Design Learn Photoshop, Illustrator, Canva, logo design, and branding.

Course Enrollment

Course Features

  • Courses are uploaded and managed by the School Administrator.
  • Students can enroll in multiple extra courses.
  • New courses can be added at any time without updating the website.
  • Course notes, videos, assignments, and certificates can be provided.
  • Students can monitor their learning progress after enrollment.
