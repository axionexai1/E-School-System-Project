Home Dashboard

The Home Dashboard is the first screen a student sees after logging into the system. It provides a quick overview of important information so students do not need to open every menu separately.

Dashboard Widgets

  • Welcome Message
  • Student Profile Card
  • Today's Classes
  • Attendance Summary
  • Upcoming Assignment
  • Upcoming Exam
  • Latest Announcement
  • Fee Status
  • Quick Shortcuts

Widget Description

Widget Description
Welcome Message Greets the student personally after login.
Student Profile Card Shows student's photo, name, class, section, roll number and student ID.
Today's Classes Displays today's subjects, timings, teacher names and classroom numbers.
Attendance Summary Displays attendance percentage and attendance status.
Upcoming Assignment Shows the next assignment with its due date.
Upcoming Exam Displays the next scheduled exam.
Latest Announcement Shows the newest school notice.
Fee Status Displays whether fees are Paid or Pending.
Quick Shortcuts Quick navigation buttons for Attendance, Results, Fees, Assignments, Exams and Course Content.
