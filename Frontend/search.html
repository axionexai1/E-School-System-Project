Search

Search helps students quickly find any information without going through every menu manually.

Search Categories

  • Search Subjects
  • Search Teachers
  • Search Notes
  • Search Books
  • Search Assignments
  • Search Exams
  • Search Results
  • Global Search

Search Features

  • Global Search looks across all categories at once and displays grouped search results.
  • Students can search Subjects, Teachers, Notes, Books, Assignments and Exams individually for faster results.
  • Search results display only the information related to the currently logged-in student.
