Online Applications

Submit and track leave requests

  • Announcements 0
Back to Dashboard

Students can apply for leave online without submitting paper applications. Leave requests are sent directly to the Class Teacher or School Administration for approval.

Leave Categories

  • Sick Leave
  • Urgent Personal Work
  • Brother's / Sister's Wedding
  • Other Leave

Leave Application Form

Application Guidelines

  • Student information is automatically filled from the profile.
  • Students only need to select the leave type and write the reason.
  • Medical certificates or supporting documents can be attached if needed.
  • Applications are sent directly to the Class Teacher or School Administration.
  • Students can later check whether their status is Approved, Pending, or Rejected.
