Online Applications

Students can apply for leave online without submitting paper applications. The leave request is sent directly to the Class Teacher or School Administration for approval.

Leave Types

  • Sick Leave
  • Urgent Personal Work
  • Brother's Wedding
  • Sister's Wedding
  • Other

Leave Application Form

Application Information

  • Student information is automatically filled from the profile.
  • Students only need to select the leave type and write the reason.
  • Medical certificates or supporting documents can be uploaded.
  • The application is sent directly to the Class Teacher or School Administration.
  • Students can later check whether the application is Approved, Pending, or Rejected.
